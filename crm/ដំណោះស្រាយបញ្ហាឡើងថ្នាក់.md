# ✅ ការកែលម្អប្រព័ន្ធឡើងថ្នាក់តាមស្តង់ដារសាលាកម្ពុជា

## � បញ្ហាដែលបានដោះស្រាយ

### 1. 🔴 បញ្ហា: មិនឃើញថ្នាក់ត្រូវឡើង
នៅពេលអ្នកចង់ដាក់សិស្សឡើងថ្នាក់ អ្នកមិនឃើញ dropdown "ថ្នាក់ថ្មី" ដើម្បីជ្រើសរើសទេ។

## 💡 មូលហេតុ

### 1.1 មូលហេតុ: ខ្វះថ្នាក់រៀន

ប្រព័ន្ធត្រូវការថ្នាក់ (Classroom) សម្រាប់គ្រប់ថ្នាក់រៀន (Grade) ដែលអ្នកចង់ដាក់សិស្សឡើង។

**មុនពេលដោះស្រាយ:**
- ថ្នាក់ទី១: ✅ មានរួចហើយ
- ថ្នាក់ទី២: ✅ មានរួចហើយ
- ថ្នាក់ទី៣: ❌ មិនមាន → **នេះជាបញ្ហា!**
- ថ្នាក់ទី៤: ❌ មិនមាន
- ថ្នាក់ទី៥: ❌ មិនមាន
- ថ្នាក់ទី៦: ❌ មិនមាន

ដូច្នេះ នៅពេលចង់ដាក់សិស្សពីថ្នាក់ទី២ឡើងថ្នាក់ទី៣ ប្រព័ន្ធមិនអាចរកថ្នាក់ទី៣បានទេ។

## ✅ ដំណោះស្រាយ

### 1.2 ដំណោះស្រាយ: បង្កើតថ្នាក់ដែលខ្វះ

បានបង្កើតថ្នាក់ដែលខ្វះទាំងអស់រួចហើយ! ✨

**ឥឡូវនេះ (Academic Year 2026):**
- ថ្នាក់ទី១: ✅ មាន
- ថ្នាក់ទី២: ✅ មាន
- ថ្នាក់ទី៣: ✅ បានបង្កើតថ្មី 🎉
- ថ្នាក់ទី៤: ✅ បានបង្កើតថ្មី 🎉
- ថ្នាក់ទី៥: ✅ បានបង្កើតថ្មី 🎉

## 📋 ផ្លូវឡើងថ្នាក់ដែលមានបច្ចុប្បន្ន

## 🔧 ប្រសិនបើអ្នកត្រូវការបង្កើតថ្នាក់បន្ថែម

នៅពេលណាដែលអ្នកត្រូវការថ្នាក់ថ្មីសម្រាប់ឆ្នាំសិក្សាថ្មី អ្នកអាចប្រើ command នេះ:

```bash
python manage.py create_missing_classrooms --year "2026"
```

Command នេះនឹង:
- ✅ រកថ្នាក់ដែលខ្វះដោយស្វ័យប្រវត្តិ
- ✅ បង្កើតថ្នាក់ដែលមិនទាន់មាន
- ✅ រំលងថ្នាក់ដែលមានរួចហើយ
- ✅ សុវត្ថិភាព (មិនបង្កើតស្ទួន)

### 2. 🔴 បញ្ហា: បង្ហាញចំនួនសិស្សឡើងថ្នាក់មិនត្រឹមត្រូវ

**បញ្ហា:** នៅក្នុងផ្នែកសង្ខេប ប្រព័ន្ធបានបង្ហាញ "ប្រឡងជាប់" ដោយគ្រាន់តែយកចំនួនសិស្សសរុបដកចេញ 1 ប៉ុណ្ណោះ មិនបានពិនិត្យលក្ខខណ្ឌពិតប្រាកដទេ។

**ឧទាហរណ៍:**
- សិស្សសរុប: 2 នាក់
- បង្ហាញថា "ប្រឡងជាប់: 1 នាក់" (2-1=1)
- ប៉ុន្តែពិតជា:
  - សិស្ស 1: ពិន្ទុ 75.8%, វត្តមាន 75.8% ❌ (វត្តមាន < 80%)
  - សិស្ស 2: ពិន្ទុ 72.5%, វត្តមាន 72.5% ❌ (វត្តមាន < 80%)
  - **ចំនួនដែលអាចឡើងថ្នាក់ពិតប្រាកដ: 0 នាក់!**

**ដំណោះស្រាយ:** ✅ បានកែកូដដើម្បីពិនិត្យលក្ខខណ្ឌពិតប្រាកដ
```javascript
// គណនាចំនួនសិស្សដែលបំពេញលក្ខខណ្ឌ
let eligibleCount = 0;
{% for data in students_data %}
  {% if data.can_promote %}  // ពិនិត្យ can_promote ពិតប្រាកដ
    eligibleCount++;
  {% endif %}
{% endfor %}
```

**លក្ខខណ្ឌឡើងថ្នាក់តាមស្តង់ដារសាលាកម្ពុជា:**
1. ✅ ពិន្ទុមធ្យម ≥ 50% (ឬតាមការកំណត់)
2. ✅ វត្តមាន ≥ 80% (ត្រូវមកសាលារៀងរាល់ថ្ងៃ)
3. ✅ មានពិន្ទុយ៉ាងហោចណាស់ 1 មុខវិជ្ជា

**ឥឡូវនេះ:**
- ✅ បង្ហាញចំនួន "អាចឡើងថ្នាក់" ត្រឹមត្រូវ
- ✅ បង្ហាញលក្ខខណ្ឌច្បាស់លាស់: "ពិន្ទុ ≥ 50% និង វត្តមាន ≥ 80%"
- ✅ សិស្សដែលមានវត្តមាន < 80% នឹងមាន badge "⚠ វត្តមានខ្សោយ" និងមិនអាចឡើងថ្នាក់
