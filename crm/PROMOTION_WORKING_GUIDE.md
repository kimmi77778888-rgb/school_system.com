# ✅ ការដំណើរការប្រព័ន្ធឡើងថ្នាក់ | Student Promotion System Working

## 🎯 ប្រព័ន្ធដំណើរការយ៉ាងណា | How It Works

### 1️⃣ បញ្ចូលពិន្ទុក្នុង Grade Book
**Enter scores in Grade Book:**
- ចូលទៅ **លទ្ធផលប្រឡង → បញ្ចូលពិន្ទុសញ្ញាត្រ (Grade Book - Excel Style Entry)**
- ជ្រើសរើស: ថ្នាក់ (Classroom), ឆ្នាំសិក្សា (Academic Year), ប្រភេទប្រឡង (Exam Type)
- បញ្ចូលពិន្ទុសម្រាប់មុខវិជ្ជាទាំងអស់ (រូបវិទ្យា, គណិតវិទ្យា, វិទ្យាសាស្រ្ត, ភាសាខ្មែរ...)
- ប្រព័ន្ធនឹងគណនា Average ដោយស្វ័យប្រវត្តិ

### 2️⃣ ពិនិត្យលក្ខខណ្ឌឡើងថ្នាក់
**Check Promotion Eligibility:**

ចូលទៅ **សិស្ស → ឡើងថ្នាក់**

ប្រព័ន្ធនឹងពិនិត្យ:
- ✅ **ពិន្ទុមធ្យម ≥ 50%** (គណនាពីគ្រប់មុខវិជ្ជា)
- ✅ **វត្តមាន ≥ 80%** (ត្រូវមកសាលារៀងរាល់ថ្ងៃ)
- ✅ **មានពិន្ទុយ៉ាងហោចណាស់ 1 មុខវិជ្ជា**

### 3️⃣ ដាក់សិស្សឡើងថ្នាក់
**Promote Students:**
- ជ្រើសរើស "ថ្នាក់បច្ចុប្បន្ន" → ឧទាហរណ៍: ទី២ | 2026
- ចុច "ពិនិត្យលទ្ធផល"
- មើលបញ្ជីសិស្សដែលអាចឡើងថ្នាក់បាន (✅ badge បៃតង)
- ជ្រើសរើស "ថ្នាក់ថ្មី" → ឧទាហរណ៍: ទី៣ | 2026
- ធីកសិស្សដែលចង់ឡើងថ្នាក់
- ចុច "ដាក់ឡើងថ្នាក់"

## 🔗 ទំនាក់ទំនងរវាង Grade Book និង Promotion

```
Grade Book (បញ្ជីពិន្ទុសញ្ញាត្រ)
    ↓
Score Model
    - student (សិស្ស)
    - subject (មុខវិជ្ជា: រូបវិទ្យា, គណិត...)
    - score (ពិន្ទុ)
    - max_score (ពិន្ទុអតិបរមា)
    - academic_year (ឆ្នាំសិក្សា)
    - exam_type (ប្រភេទប្រឡង)
    ↓
Promotion System (ប្រព័ន្ធឡើងថ្នាក់)
    - គណនាពិន្ទុមធ្យមពីគ្រប់មុខវិជ្ជា
    - ពិនិត្យវត្តមាន
    - កំណត់សិទ្ធិឡើងថ្នាក់
    ↓
StudentHistory (ប្រវត្តិសិស្ស)
    - រក្សាទុកពិន្ទុមធ្យម
    - រក្សាទុកវត្តមាន
    - រក្សាទុកថ្នាក់ដែលឡើង
```

## 📝 ឧទាហរណ៍ការគណនា | Example Calculation

### សិស្ស: លោក ញី (STU-0002)

**ពិន្ទុក្នុង Grade Book:**
| មុខវិជ្ជា | ពិន្ទុ | អតិបរមា | ភាគរយ |
|----------|-------|---------|-------|
| រូបវិទ្យា | 0 | 100 | 0% |
| គណិតវិទ្យា | 0 | 100 | 0% |
| វិទ្យាសាស្រ្ត | 0 | 100 | 0% |
| ភាសាខ្មែរ | 0 | 100 | 0% |

**ពិន្ទុមធ្យម:** (0 + 0 + 0 + 0) / 4 = **0%**

**វត្តមាន:** 
- មកវត្តមាន: 0 ថ្ងៃ
- សរុប: 0 ថ្ងៃ
- ភាគរយ: **0%**

**លទ្ធផល:** ❌ **មិនអាចឡើងថ្នាក់** (ពិន្ទុ < 50%, វត្តមាន < 80%)

### សិស្ស: សុខ សុផល (STU-0001)

**ពិន្ទុក្នុង Grade Book:**
| មុខវិជ្ជា | ពិន្ទុ | អតិបរមា | ភាគរយ |
|----------|-------|---------|-------|
| រូបវិទ្យា | 85 | 100 | 85% |
| គណិតវិទ្យា | 90 | 100 | 90% |
| វិទ្យាសាស្រ្ត | 78 | 100 | 78% |
| ភាសាខ្មែរ | 82 | 100 | 82% |

**ពិន្ទុមធ្យម:** (85 + 90 + 78 + 82) / 4 = **83.75%** ✅

**វត្តមាន:** 
- មកវត្តមាន: 160 ថ្ងៃ
- សរុប: 180 ថ្ងៃ  
- ភាគរយ: **88.9%** ✅

**លទ្ធផល:** ✅ **អាចឡើងថ្នាក់** (ពិន្ទុ ≥ 50%, វត្តមាន ≥ 80%)

## 🎓 លក្ខណៈពិសេសនៃប្រព័ន្ធ | System Features

### ✅ ការគណនាដោយស្វ័យប្រវត្តិ
- ពិន្ទុមធ្យម = សរុបភាគរយពិន្ទុគ្រប់មុខវិជ្ជា / ចំនួនមុខវិជ្ជា
- វត្តមាន = (ថ្ងៃមកវត្តមាន / ថ្ងៃសរុប) × 100%

### ✅ Strict Grade Progression
- មិនអាចរំលងថ្នាក់ (ថ្នាក់ 1 → ថ្នាក់ 3 ❌)
- ត្រូវឡើងតែថ្នាក់បន្ទាប់ (ថ្នាក់ 1 → ថ្នាក់ 2 ✅)

### ✅ Level Transition Detection
- ថ្នាក់ទី 6 → ថ្នាក់ទី 7: ផ្ទេរពីបឋមសិក្សាទៅបឋមភូមិ
- ថ្នាក់ទី 9 → ថ្នាក់ទី 10: ផ្ទេរពីបឋមភូមិទៅមធ្យមភូមិ
- ថ្នាក់ទី 12: បញ្ចប់ការសិក្សា

### ✅ History Preservation
- រក្សាទុកពិន្ទុមធ្យម
- រក្សាទុកវត្តមាន
- រក្សាទុកថ្នាក់ដែលឡើង
- រក្សាទុកកាលបរិច្ឆេទ

## 🔧 របៀបប្រើប្រាស់ទាំងស្រុង | Complete Usage

### Step 1: បង្កើតថ្នាក់រៀនសម្រាប់ឆ្នាំសិក្សា
```bash
python manage.py create_missing_classrooms --year "2026"
```

### Step 2: បញ្ចូលពិន្ទុ
- ចូល: **លទ្ធផលប្រឡង → បញ្ចូលពិន្ទុសញ្ញាត្រ**
- ជ្រើសថ្នាក់, ឆ្នាំ, ប្រភេទប្រឡង
- បញ្ចូលពិន្ទុគ្រប់មុខវិជ្ជា

### Step 3: បញ្ចូលវត្តមាន
- ចូល: **វត្តមាន → បញ្ចូលវត្តមាន**
- កត់ត្រាវត្តមានប្រចាំថ្ងៃ (Present/Absent/Late)

### Step 4: ដាក់ឡើងថ្នាក់
- ចូល: **សិស្ស → ឡើងថ្នាក់**
- ពិនិត្យលទ្ធផល
- ជ្រើសថ្នាក់ថ្មី
- ដាក់ឡើងថ្នាក់
