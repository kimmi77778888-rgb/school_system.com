# មគ្គុទ្ទេសន៍ដាក់សិស្សឡើងថ្នាក់ (Student Promotion Guide)

## 🎯 គោលបំណង

មុខងារនេះអនុញ្ញាតឲ្យគ្រប់គ្រងការដាក់សិស្សឡើងថ្នាក់ដោយស្វ័យប្រវត្តិ ដោយផ្អែកលើលទ្ធផលប្រឡង។

---

## 📋 លក្ខខណ្ឌដាក់ឡើងថ្នាក់

សិស្សអាចឡើងថ្នាក់បាន **បើប្រឡងជាប់គ្រប់មុខវិជ្ជា**:

✅ **ជាប់** = ពិន្ទុ ≥ 50% (ឬតាមដែលកំណត់)
❌ **ធ្លាក់** = ពិន្ទុ < 50%

### ឧទាហរណ៍:

#### សិស្ស A - **អាចឡើងថ្នាក់** ✅
```
ថ្នាក់ទី១ (Grade 1)
├── គណិតវិទ្យា: 80/100 (80%) → ✓ ជាប់
├── ភាសាខ្មែរ:   75/100 (75%) → ✓ ជាប់
├── វិទ្យាសាស្ត្រ: 65/100 (65%) → ✓ ជាប់
└── ភាសាអង់គ្លេស: 70/100 (70%) → ✓ ជាប់

លទ្ធផល: ជាប់ទាំងអស់ → ឡើងថ្នាក់ទី២ ✅
```

#### សិស្ស B - **មិនអាចឡើងថ្នាក់** ❌
```
ថ្នាក់ទី១ (Grade 1)
├── គណិតវិទ្យា: 90/100 (90%) → ✓ ជាប់
├── ភាសាខ្មែរ:   45/100 (45%) → ✗ ធ្លាក់ (បរាជ័យ!)
├── វិទ្យាសាស្ត្រ: 85/100 (85%) → ✓ ជាប់
└── ភាសាអង់គ្លេស: 78/100 (78%) → ✓ ជាប់

លទ្ធផល: ធ្លាក់ភាសាខ្មែរ → នៅថ្នាក់ដដែល ❌
```

## 🚀 ជំហានប្រើប្រាស់

### ជំហានទី 1: ចូលទៅកាន់ទំព័រដាក់សិស្សឡើងថ្នាក់

**URL:** `/school/students/promote/`

```
┌─────────────────────────────────────────┐

│                                         │

│  ឆ្នាំសិក្សា:       [2023-2024 ▼]      │
```

**កំណត់:**
- **ថ្នាក់បច្ចុប្បន្ន**: ថ្នាក់ដែលសិស្សកំពុងរៀន (ឧ. ថ្នាក់ទី១)
- **ឆ្នាំសិក្សា**: ឆ្នាំសិក្សាដែលមានលទ្ធផលប្រឡង
- **ពិន្ទុជាប់**: ភាគរយអប្បបរមាដើម្បីជាប់ (លំនាំដើម: 50%)

- **ធ្លាក់**: ចំនួនមុខវិជ្ជាប្រឡងធ្លាក់
- **មធ្យមភាគ**: ពិន្ទុមធ្យមភាគគ្រប់មុខវិជ្ជា

## 📝 ឧទាហរណ៍ពិតប្រាកដ

### ស្ថានភាព: ដាក់សិស្សឡើងពីថ្នាក់ទី១ ទៅថ្នាក់ទី២

#### **មុនដាក់ឡើងថ្នាក់:**

**ថ្នាក់ទី១ A (2023-2024)**

| សិស្ស | គណិត | ខ្មែរ | វិទ្យា | អង់គ្លេស | លទ្ធផល |
|--------|------|------|--------|----------|---------|
| សុផារ៉ា | 80% | 75% | 85% | 70% | ✅ ជាប់ |
| ដារ៉ា   | 90% | 45% | 85% | 78% | ❌ ធ្លាក់ |
| រដ្ឋា  | 95% | 88% | 92% | 85% | ✅ ជាប់ |
| សុខា   | 65% | 70% | 68% | 72% | ✅ ជាប់ |
| ពេជ្រ  | 55% | 48% | 60% | 52% | ❌ ធ្លាក់ |

**ជំហានដាក់ឡើងថ្នាក់:**

1. ចូល: `/school/students/promote/`
2. ជ្រើសរើស:
   - ថ្នាក់: **ថ្នាក់ទី១ A**
   - ឆ្នាំ: **2023-2024**
   - ពិន្ទុជាប់: **50%**
3. ចុច **"ពិនិត្យលទ្ធផល"**
4. បង្ហាញលទ្ធផល:
   ```
   សិស្សសរុប: 5 នាក់
   អាចឡើងថ្នាក់: 3 នាក់ (សុផារ៉ា, រដ្ឋា, សុខា)
   មិនអាចឡើងថ្នាក់: 2 នាក់ (ដារ៉ា, ពេជ្រ)
   ```
5. ជ្រើសរើសថ្នាក់ថ្មី: **ថ្នាក់ទី២ A**
6. ធីកសិស្ស:
   - ☑ សុផារ៉ា
   - ☑ រដ្ឋា
   - ☑ សុខា
7. ចុច **"ដាក់ឡើងថ្នាក់"**
8. បញ្ជាក់: **"តើអ្នកប្រាកដជាចង់ដាក់សិស្សទាំងនេះឡើងថ្នាក់មែនទេ?"**
9. ចុច **OK**

#### **បន្ទាប់ពីដាក់ឡើងថ្នាក់:**

**ថ្នាក់ទី១ A (នៅសល់):**
- ដារ៉ា (ប្រឡងធ្លាក់ភាសាខ្មែរ)
- ពេជ្រ (ប្រឡងធ្លាក់ភាសាខ្មែរ)

**ថ្នាក់ទី២ A (បន្ថែមថ្មី):**
- សុផារ៉ា ✓
- រដ្ឋា ✓
- សុខា ✓

## ⚙️ ការកំណត់

### 1. ប្តូរពិន្ទុជាប់

អាចប្តូរពិន្ទុអប្បបរមាដើម្បីជាប់:

- **40%** = ងាយជាប់ (រួមបញ្ចូលសិស្សដែលមានពិន្ទុទាប)
- **50%** = លំនាំដើម (មធ្យម)
- **60%** = ស្តង់ដារខ្ពស់

### 2. ថ្នាក់ថ្មី

ប្រព័ន្ធនឹងបង្ហាញតែថ្នាក់ដែលខ្ពស់ជាងថ្នាក់បច្ចុប្បន្ន:

```
ថ្នាក់បច្ចុប្បន្ន: ថ្នាក់ទី១
ថ្នាក់ថ្មីដែលអាចជ្រើសបាន:
  - ថ្នាក់ទី២ A
  - ថ្នាក់ទី២ B
  - ថ្នាក់ទី៣ (បើមាន)
```

## ❓ សំណួរញឹកញាប់

### Q1: បើសិស្សប្រឡងធ្លាក់មួយមុខវិជ្ជាអាចឡើងថ្នាក់បានទេ?

**A:** ❌ ទេ។ សិស្សត្រូវប្រឡងជាប់**គ្រប់មុខវិជ្ជា**ទើបអាចឡើងថ្នាក់។

### Q2: តើអាចដាក់សិស្សឡើងថ្នាក់ម្តងមួយនាក់បានទេ?

**A:** ✅ បាន។ ធីកតែសិស្សដែលចង់ឡើងថ្នាក់។

### Q3: បើមិនមានលទ្ធផលប្រឡងធ្វើម៉េច?

**A:** សិស្សទាំងនោះនឹងបង្ហាញជា "មិនមានពិន្ទុ" ហើយមិនអាចឡើងថ្នាក់បានទេ។

### Q4: តើអាចដាក់សិស្សឡើង 2 ថ្នាក់រំលងបានទេ? (ឧ. ទី១→ទី៣)

**A:** ✅ បាន។ ជ្រើសរើសថ្នាក់ណាក៏បាន ដែលខ្ពស់ជាងថ្នាក់បច្ចុប្បន្ន។

### Q5: បើដាក់ឡើងថ្នាក់ខុសធ្វើម៉េច?

**A:** អាចដាក់ត្រលប់វិញដោយ:
1. ចូល **Student List**
2. **Edit** សិស្សម្នាក់ៗ
3. ប្តូរ **Classroom** ទៅថ្នាក់ចាស់
