# 🔧 ដំណោះស្រាយបញ្ហា "មិនអាចប្រើមុខងារឡើងថ្នាក់"
# Solution for "Cannot Use Promotion Feature"

## ❌ បញ្ហា (Problem)

នៅពេលចង់ដាក់សិស្សឡើងថ្នាក់ អ្នកមិនអាចប្រើមុខងារ **"សិស្សឡើងថ្នាក់"** បានទេ។

When trying to promote students, you cannot use the **"Student Promotion"** feature.

## 🔍 មូលហេតុ (Root Cause)

ខ្ញុំបានពិនិត្យប្រព័ន្ធរបស់អ្នក និងរកឃើញបញ្ហាដូចខាងក្រោម:

```
1️⃣ GRADES (ថ្នាក់)
   ✅ មានថ្នាក់ពី Grade 1 ដល់ Grade 6
   ✅ គ្រប់ថ្នាក់មាន grade_number ត្រឹមត្រូវ

2️⃣ CLASSROOMS (ថ្នាក់រៀន)
   ✅ មានថ្នាក់រៀនគ្រប់គ្រាន់សម្រាប់ឡើងថ្នាក់
   ✅ Grade 1 អាចឡើងទៅ Grade 2
   ✅ Grade 2 អាចឡើងទៅ Grade 3
   ✅ ... (រហូតដល់ Grade 6)

3️⃣ STUDENTS (សិស្ស)
   ✅ មានសិស្សសកម្ម 1 នាក់
   ✅ សិស្សស្ថិតក្នុងថ្នាក់ "ទី១ | 2026"

4️⃣ SCORES (ពិន្ទុ) ❌❌❌ នេះជាបញ្ហា!
   ❌ សិស្សមិនមានពិន្ទុប្រឡងសោះ!
   ❌ Students with scores: 0
   ❌ Students without scores: 1
```

### 🎯 បញ្ហាសំខាន់

**សិស្សមិនមានពិន្ទុប្រឡង (No Exam Scores)** ដូច្នេះប្រព័ន្ធមិនអនុញ្ញាតឱ្យឡើងថ្នាក់ទេ។

## 📋 លក្ខខណ្ឌឡើងថ្នាក់ (Promotion Requirements)

ដើម្បីឡើងថ្នាក់ សិស្សត្រូវបំពេញលក្ខខណ្ឌទាំងអស់នេះ:

```
✅ 1. ពិន្ទុមធ្យម ≥ 50% (Average Score ≥ 50%)
✅ 2. មានពិន្ទុយ៉ាងហោចណាស់ 1 មុខវិជ្ជា (At least 1 subject with score)
✅ 3. វត្តមាន ≥ 80% (Attendance ≥ 80%)
```

### ស្ថានភាពបច្ចុប្បន្នរបស់សិស្សអ្នក:

```
❌ ពិន្ទុមធ្យម: គ្មានពិន្ទុ (No scores)
❌ ចំនួនមុខវិជ្ជា: 0 មុខវិជ្ជា
❓ វត្តមាន: មិនដឹងច្បាស់ (Unknown)
```

## ✅ ដំណោះស្រាយ (Solution)

### វិធីទី 1: បន្ថែមពិន្ទុដោយដៃ (Manual Entry)

#### ជំហានទី 1: បន្ថែមមុខវិជ្ជា (Add Subjects)

1. ចូលទៅ **Django Admin** (`/admin`)
2. ចុច **Subjects** (មុខវិជ្ជា)
3. បង្កើតមុខវិជ្ជាដែលអ្នកត្រូវការ:
   - ភាសាខ្មែរ (Khmer Language)
   - គណិតវិទ្យា (Mathematics)
   - វិទ្យាសាស្ត្រ (Science)
   - សង្គមវិទ្យា (Social Studies)
   - ភាសាអង់គ្លេស (English)

#### ជំហានទី 2: បន្ថែមពិន្ទុសិស្ស (Add Student Scores)

**Option A: តាម Django Admin**

1. ចូលទៅ **Django Admin** → **Scores**
2. ចុច **"Add Score"**
3. ជ្រើសរើស:
   - **Student**: Hunneng Nim (2)
   - **Subject**: ភាសាខ្មែរ
   - **Score**: 75 (ឧទាហរណ៍)
   - **Max Score**: 100
   - **Academic Year**: 2026
4. ចុច **Save**
5. **សាកធ្វើម្តងទៀត** សម្រាប់មុខវិជ្ជាផ្សេងទៀត

**Option B: តាមរយៈ Grade Book (បើមាន)**

1. ទៅកាន់ **Grade Book** (បញ្ជីពិន្ទុ)
2. ជ្រើសរើសថ្នាក់រៀន
3. បញ្ចូលពិន្ទុសិស្សនីមួយៗ

#### ជំហានទី 3: ពិនិត្យវត្តមាន (Check Attendance)

1. ចូលទៅ **Attendance** (វត្តមាន)
2. កត់ត្រាវត្តមានប្រចាំថ្ងៃ
3. ត្រូវមាន **≥ 80%** វត្តមាន

### វិធីទី 2: ប្រើ Script ស្វ័យប្រវត្តិ (Automated Script)

យើងបានបង្កើត script ដើម្បីជួយអ្នក:

```bash
cd d:\Monday-Friday-Year3S1\Monday\python\crm
python add_student_scores.py
```

Script នេះនឹង:
- ✅ បង្កើតមុខវិជ្ជាដោយស្វ័យប្រវត្តិ (បើមិនទាន់មាន)
- ✅ ឱ្យអ្នកបញ្ចូលពិន្ទុសម្រាប់គ្រប់មុខវិជ្ជា
- ✅ បង្កើតកំណត់ត្រាវត្តមានគំរូ (បើចង់បាន)
- ✅ ពិនិត្យលក្ខខណ្ឌឡើងថ្នាក់ដោយស្វ័យប្រវត្តិ

## 🐛 បញ្ហាទូទៅ (Common Issues)

### បញ្ហា 1: មិនឃើញប៊ូតុង "ដាក់សិស្សឡើងថ្នាក់"

**ដំណោះស្រាយ:**
- ត្រូវ login ជា **Admin** ឬ **Teacher**
- Student មិនមានសិទ្ធិឡើងថ្នាក់សិស្សឡើយ

### បញ្ហា 2: មិនឃើញ "ថ្នាក់ថ្មី" dropdown

**ដំណោះស្រាយ:**
- ត្រូវមានថ្នាក់បន្ទាប់ (ថ្នាក់ទី 2, 3, 4...)
- ពិនិត្យថាថ្នាក់ទាំងនោះមាន grade_number ត្រឹមត្រូវ

### បញ្ហា 3: សិស្សមិនបង្ហាញក្នុងបញ្ជី

**ដំណោះស្រាយ:**

- ពិន្ទុមធ្យម ≥ 50%
- វត្តមាន ≥ 80%

### បញ្ហា 4: Error នៅពេលឡើងថ្នាក់

**ដំណោះស្រាយ:**
