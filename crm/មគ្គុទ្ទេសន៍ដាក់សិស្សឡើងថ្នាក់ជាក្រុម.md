# មគ្គុទ្ទេសន៍ដាក់សិស្សឡើងថ្នាក់ជាក្រុម
## Guide for Bulk Student Promotion

## 🎯 តើមុខងារនេះជាអ្វី?

**ដាក់សិស្សឡើងថ្នាក់ជាក្រុម** គឺជាមុខងារដែលអនុញ្ញាតឱ្យអ្នកដាក់សិស្សទាំងមូលថ្នាក់ឡើងថ្នាក់ក្រោយក្នុងពេលតែមួយ ជំនួសឱ្យការដាក់ម្នាក់ៗ។

**ឧទាហរណ៍:**
- ដាក់សិស្សទាំងអស់ពីថ្នាក់ទី១ ឡើងថ្នាក់ទី២
- ដាក់សិស្សទាំងអស់ពីថ្នាក់ទី២ ឡើងថ្នាក់ទី៣
- ព្រមទាំងរក្សាប្រវត្តិសិក្សារបស់សិស្សនីមួយៗ

---

## 📍 របៀបចូលប្រើប្រាស់

### ជំហានទី 1: ចូលទៅកាន់ទំព័រដាក់សិស្សឡើងថ្នាក់

**វិធីទី 1 - តាមរយៈ Menu:**
1. ចុចលើ **"សិស្ស"** នៅ sidebar ខាងឆ្វេង
2. ជ្រើសរើស **"ដាក់សិស្សឡើងថ្នាក់"**

**វិធីទី 2 - តាមរយៈ URL:**
```
http://localhost:8000/students/promote/
```

## 🔍 ជំហានទី 2: ជ្រើសរើសថ្នាក់និងឆ្នាំសិក្សា

នៅលើទំព័រ អ្នកនឹងឃើញ Form ដូចខាងក្រោម:

```
┌──────────────────────────────────────────┐
│  ដាក់សិស្សឡើងថ្នាក់ជាក្រុម              │
│                                          │
│  [ជ្រើសរើសថ្នាក់បច្ចុប្បន្ន]               │
│  └─ ទី១ | 2026                          │
│  └─ ទី២ | 2026                          │
│  └─ ទី៣ | 2026                          │
│                                          │
│  [ជ្រើសរើសឆ្នាំសិក្សា (ស្រេច)]           │
│  └─ 2026                                │
│  └─ Year3                               │
│                                          │
│  [ពិន្ទុជាប់] 50%                        │
│                                          │
│  [ពិនិត្យលទ្ធផល]                         │
└──────────────────────────────────────────┘
```

### ការពន្យល់:
- **ថ្នាក់បច្ចុប្បន្ន**: ថ្នាក់ដែលសិស្សកំពុងសិក្សា
- **ឆ្នាំសិក្សា**: ឆ្នាំសិក្សាដែលចង់គណនាពិន្ទុ (ជ្រើស "ទាំងអស់" ដើម្បីយកពិន្ទុគ្រប់ឆ្នាំ)
- **ពិន្ទុជាប់**: ពិន្ទុអប្បបរមាដើម្បីឡើងថ្នាក់ (លំនាំដើម: 50%)

## 📊 ជំហានទី 3: ពិនិត្យលទ្ធផល

បន្ទាប់ពីចុច **"ពិនិត្យលទ្ធផល"** អ្នកនឹងឃើញតារាងបង្ហាញ:

```
┌────────────────────────────────────────────────────────────┐
│  សង្ខេប                                                    │
│  • សិស្សសរុប: 30 នាក់                                      │
│  • អាចឡើងថ្នាក់: 25 នាក់ (ពិន្ទុ ≥ 50% និង វត្តមាន ≥ 80%) │
│  • មិនអាចឡើងថ្នាក់: 5 នាក់                                │
└────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ # │ សិស្ស    │ ពិន្ទុ  │ វត្តមាន │ ថ្នាក់ថ្មី │ ស្ថានភាព  │
├───┼──────────┼─────────┼─────────┼──────────┼───────────┤
│ 1 │ សុខា     │ 85.5%   │ 95.0%   │ ទី២     │ ✅ អាចឡើង │
│ 2 │ វាសនា    │ 78.2%   │ 88.5%   │ ទី២     │ ✅ អាចឡើង │
│ 3 │ ពិសី     │ 45.8%   │ 82.0%   │ -        │ ❌ ពិន្ទុខ្សោយ │
│ 4 │ ដារ៉ា    │ 92.0%   │ 75.0%   │ -        │ ⚠ វត្តមានខ្សោយ│
└───┴──────────┴─────────┴─────────┴──────────┴───────────┘
```


### ការពន្យល់ Status Icons:
- ✅ **អាចឡើងថ្នាក់**: ពិន្ទុ ≥ 50% និង វត្តមាន ≥ 80%
- ❌ **ពិន្ទុខ្សោយ**: ពិន្ទុ < 50%
- ⚠️ **វត្តមានខ្សោយ**: វត្តមាន < 80%
- ⚠️ **គ្មានពិន្ទុ**: មិនមានពិន្ទុសោះ

## ✅ ជំហានទី 4: ជ្រើសរើសសិស្សដែលចង់ដាក់ឡើងថ្នាក់

### វិធីទី 1 - ជ្រើសរើសម្នាក់ៗ:
ចុច checkbox នៅមុខឈ្មោះសិស្សដែលអ្នកចង់ដាក់ឡើងថ្នាក់

### វិធីទី 2 - ជ្រើសរើសទាំងអស់:
ចុច checkbox នៅក្បាលតារាង (ជាប់ "ឈ្មោះសិស្ស") ដើម្បីជ្រើសរើសសិស្សទាំងអស់ដែលអាចឡើងថ្នាក់

### វិធីទី 3 - ជ្រើសរើសតែអ្នកដែលអាចឡើង:
ប្រព័ន្ធនឹងជ្រើសរើសតែសិស្សដែលមាន status "អាចឡើងថ្នាក់" ដោយស្វ័យប្រវត្តិ

## 🎯 ជំហានទី 5: ជ្រើសរើសថ្នាក់ថ្មី

បន្ទាប់ពីជ្រើសរើសសិស្ស អ្នកត្រូវជ្រើសរើស **"ថ្នាក់ថ្មី"** សម្រាប់សិស្សទាំងនោះ។

```
[ជ្រើសរើសថ្នាក់ថ្មី]
└─ ទី២ | 2026
└─ ទី២ | Year3
```

**ចំណាំ:** 
- អ្នកអាចជ្រើសរើសថ្នាក់ណាក៏បាន ប៉ុន្តែប្រព័ន្ធ recommend ថ្នាក់បន្ទាប់តាមលំដាប់
- ឧទាហរណ៍: ថ្នាក់ទី១ → ថ្នាក់ទី២, ថ្នាក់ទី២ → ថ្នាក់ទី៣

## 📋 លក្ខខណ្ឌឡើងថ្នាក់តាមស្តង់ដារសាលាកម្ពុជា

### 1. ពិន្ទុមធ្យម (Average Score)
- **អប្បបរមា:** 50% (អាចកំណត់បាន)
- **របៀបគណនា:** យកពិន្ទុមធ្យមពីគ្រប់មុខវិជ្ជា
- **ឧទាហរណ៍:**
  - គណិតវិទ្យា: 80/100 (80%)
  - ភាសាខ្មែរ: 75/100 (75%)
  - ភាសាអង់គ្លេស: 70/100 (70%)
  - **មធ្យម = (80 + 75 + 70) / 3 = 75%** ✅ អាចឡើង

### 2. វត្តមាន (Attendance)
- **អប្បបរមា:** 80%
- **របៀបគណនា:** (ចំនួនថ្ងៃមកសាលា / ចំនួនថ្ងៃសរុប) × 100
- **ឧទាហរណ៍:**
  - ចំនួនថ្ងៃសរុប: 100 ថ្ងៃ
  - មកសាលា: 85 ថ្ងៃ
  - **វត្តមាន = 85/100 = 85%** ✅ អាចឡើង

### 3. មុខវិជ្ជា (Subjects)
- **ចាំបាច់:** ត្រូវមានពិន្ទុយ៉ាងហោចណាស់ 1 មុខវិជ្ជា
- ប្រសិនបើសិស្សគ្មានពិន្ទុសោះ → មិនអាចឡើងថ្នាក់

## 🔍 ករណីពិសេស

### ករណីទី 1: សិស្សមានពិន្ទុល្អ ប៉ុន្តែវត្តមានខ្សោយ

```
សិស្ស: ដារ៉ា
ពិន្ទុមធ្យម: 92% ✅
វត្តមាន: 75% ❌ (< 80%)
ស្ថានភាព: មិនអាចឡើងថ្នាក់
```

**មូលហេតុ:** ទោះបីពិន្ទុល្អក៏ដោយ ប៉ុន្តែវត្តមានមិនគ្រប់គ្រាន់។ សាលាត្រូវការឱ្យសិស្សមកសាលារៀងរាល់ថ្ងៃ។

### ករណីទី 2: សិស្សវត្តមានល្អ ប៉ុន្តែពិន្ទុខ្សោយ

```
សិស្ស: ពិសី
ពិន្ទុមធ្យម: 45% ❌ (< 50%)
វត្តមាន: 95% ✅
ស្ថានភាព: មិនអាចឡើងថ្នាក់
```

**មូលហេតុ:** ទោះបីមកសាលាទៀងទាត់ ប៉ុន្តែពិន្ទុមិនគ្រប់គ្រាន់។ សិស្សត្រូវការរៀនបន្ថែម។

### ករណីទី 3: សិស្សមិនមានពិន្ទុ

```
សិស្ស: បូផា
ពិន្ទុមធ្យម: គ្មាន ❌
វត្តមាន: 88% ✅
ស្ថានភាព: មិនអាចឡើងថ្នាក់
```

**មូលហេតុ:** មិនមានពិន្ទុសម្រាប់គណនា។ ត្រូវបញ្ចូលពិន្ទុសិន។

### ឧទាហរណ៍ទី 2: ដាក់សិស្សចុងឆ្នាំសិក្សា

**ស្ថានភាព:** ចុងឆ្នាំសិក្សា 2025-2026, ចង់ដាក់សិស្សឡើងឆ្នាំ 2026-2027

2. បន្ទាប់មកដាក់សិស្សឡើងថ្នាក់តាមធម្មតា

- ប្រព័ន្ធនឹងរក្សា History ទាំងអស់

### 2. ត្រួតពិនិត្យថ្នាក់ថ្មី
- ប្រាកដថាមានថ្នាក់ថ្មីមុនពេលដាក់ឡើងថ្នាក់
- ប្រាកដថាថ្នាក់ថ្មីស្ថិតក្នុងឆ្នាំសិក្សាត្រឹមត្រូវ

### 3. Backup ទិន្នន័យ
- Backup database មុនពេលដាក់ឡើងថ្នាក់ច្រើន

## 🔧 ដោះស្រាយបញ្ហា

### បញ្ហា: មិនឃើញ "ថ្នាក់ថ្មី" dropdown

**ដំណោះស្រាយ:**
1. ត្រួតពិនិត្យថាមានថ្នាក់បន្ទាប់ក្នុងប្រព័ន្ធ
2. ប្រសិនបើមិនមាន បង្កើតថ្នាក់ថ្មីតាមរយៈ Admin
3. ឬប្រើ command: `python manage.py create_missing_classrooms`

### បញ្ហា: ចំនួនសិស្សខុស

**ដំណោះស្រាយ:**
1. Refresh page (F5)
2. ត្រួតពិនិត្យ filter "ឆ្នាំសិក្សា" ត្រឹមត្រូវ
3. ត្រួតពិនិត្យថាសិស្សមាន status "ACTIVE"

### បញ្ហា: មិនអាចដាក់ឡើងថ្នាក់

**ដំណោះស្រាយ:**
1. ត្រួតពិនិត្យ error message
2. ត្រួតពិនិត្យថាមាន permission (admin or teacher)
3. ត្រួតពិនិត្យថាសិស្សមានលក្ខខណ្ឌគ្រប់គ្រាន់
