# 📚 មគ្គុទ្ទេសន៍ប្រព័ន្ធឡើងថ្នាក់ - Student Promotion System Guide

## 🎯 ការឡើងថ្នាក់គឺជាអ្វី? (What is Student Promotion?)

ការឡើងថ្នាក់ (Promotion) គឺជាដំណើរការដាក់សិស្សពីថ្នាក់បច្ចុប្បន្នទៅថ្នាក់ខ្ពស់ជាងមុន។

**ឧទាហរណ៍:**
- សិស្សនៅថ្នាក់ទី១ ឡើងទៅថ្នាក់ទី២ ✅
- សិស្សនៅថ្នាក់ទី២ ឡើងទៅថ្នាក់ទី៣ ✅
- សិស្សនៅថ្នាក់ទី៦ ឡើងទៅថ្នាក់ទី៧ (ផ្ទេរកម្រិត) ✅

---

## 🏫 ប្រព័ន្ធអប់រំកម្ពុជា (Cambodia Education System)

### កម្រិតសិក្សា (Education Levels)

```
បឋមសិក្សា (Primary)        | ថ្នាក់ទី១-៦    | Grade 1-6
                              ↓
បឋមភូមិ (Lower Secondary)    | ថ្នាក់ទី៧-៩    | Grade 7-9
                              ↓
មធ្យមភូមិ (Upper Secondary)   | ថ្នាក់ទី១០-១២  | Grade 10-12
                              ↓
                         បញ្ចប់ការសិក្សា 🎓
```

---

## ✅ លក្ខខណ្ឌឡើងថ្នាក់ (Promotion Criteria)

### 1️⃣ ពិន្ទុមធ្យម (Average Score)
- ត្រូវតែមាន **ពិន្ទុមធ្យម ≥ 50%** លើគ្រប់មុខវិជ្ជា
- ត្រូវមានពិន្ទុយ៉ាងហោចណាស់ 1 មុខវិជ្ជា

### 2️⃣ វត្តមាន (Attendance)
- ត្រូវមកសាលា **≥ 80%** នៃថ្ងៃសរុប
- ឧទាហរណ៍: ប្រសិនបើមាន 100 ថ្ងៃសរុប ត្រូវមកយ៉ាងហោចណាស់ 80 ថ្ងៃ

### 3️⃣ ឡើងថ្នាក់បន្ទាប់ប៉ុណ្ណោះ (Sequential Progression Only)
- **អនុញ្ញាត ✅:** ថ្នាក់ទី១ → ថ្នាក់ទី២ (ឡើងបន្តបន្ទាប់)
- **មិនអនុញ្ញាត ❌:** ថ្នាក់ទី១ → ថ្នាក់ទី៣ (រំលងថ្នាក់)

### 4️⃣ ការផ្ទេរកម្រិត (Level Transitions)
- **ថ្នាក់ទី៦ → ថ្នាក់ទី៧:** ផ្ទេរពីបឋមសិក្សាទៅបឋមភូមិ ✅
- **ថ្នាក់ទី៩ → ថ្នាក់ទី១០:** ផ្ទេរពីបឋមភូមិទៅមធ្យមភូមិ ✅
- **ថ្នាក់ទី១២:** បញ្ចប់ការសិក្សា 🎓

---

## 📋 ជំហានដើម្បីដាក់សិស្សឡើងថ្នាក់ (Steps to Promote Students)

### ជំហានទី១: ត្រៀមរៀបចំថ្នាក់ថ្មី

មុននឹងដាក់សិស្សឡើងថ្នាក់ អ្នកត្រូវ**បង្កើតថ្នាក់រៀនថ្មី** សម្រាប់ថ្នាក់បន្ទាប់។

#### ឧទាហរណ៍:
ប្រសិនបើអ្នកចង់ដាក់សិស្សពីថ្នាក់ទី២ឡើងថ្នាក់ទី៣:
- ត្រូវមានថ្នាក់ទី២ រួចហើយ ✅
- ត្រូវមានថ្នាក់ទី៣ ដើម្បីដាក់សិស្សឡើង ✅

#### របៀបបង្កើតថ្នាក់ដែលខ្វះ:

**ផ្លូវទី១: ប្រើ Command (ងាយស្រួល)** 🚀
```bash
python manage.py create_missing_classrooms --year "2026"
```

**ផ្លូវទី២: បង្កើតដោយដៃ**
1. ទៅកាន់ "ថ្នាក់រៀន" (Classrooms)
2. ចុច "បន្ថែមថ្នាក់រៀន" (Add Classroom)
3. ជ្រើសរើសថ្នាក់ (Grade) និងឆ្នាំសិក្សា (Academic Year)
4. រក្សាទុក (Save)

---

### ជំហានទី២: ចូលទៅកាន់ផ្នែកឡើងថ្នាក់

1. ចូលទៅកាន់ប្រព័ន្ធ (Login)
2. ចុច **"សិស្ស"** (Students)
3. ចុច **"ដាក់សិស្សឡើងថ្នាក់"** (Promote Students)

---

### ជំហានទី៣: ជ្រើសរើសថ្នាក់និងឆ្នាំសិក្សា

1. **ជ្រើសរើសថ្នាក់បច្ចុប្បន្ន:**
   - ឧទាហរណ៍: "ទី២ | 2026"

2. **ជ្រើសរើសឆ្នាំសិក្សា** (ជម្រើស):
   - អាចទុកទទេ (ប្រើឆ្នាំនៃថ្នាក់)
   - ឬជ្រើសរើសឆ្នាំផ្សេង

3. **កំណត់ពិន្ទុជាប់:**
   - លំនាំដើម: 50%
   - អ្នកអាចប្តូរបាន (ឧ: 60%, 70%)

4. ចុច **"ពិនិត្យលទ្ធផល"** (Check Results)

---

### ជំហានទី៤: ពិនិត្យបញ្ជីសិស្ស

បន្ទាប់ពីចុច "ពិនិត្យលទ្ធផល" អ្នកនឹងឃើញ:

#### 📊 សង្ខេប (Summary)
- **សិស្សសរុប:** ចំនួនសិស្សទាំងអស់
- **អាចឡើងថ្នាក់:** ចំនួនសិស្សដែលបំពេញលក្ខខណ្ឌ ✅
- **លក្ខខណ្ឌ:** ពិន្ទុ និង វត្តមាន

#### 📋 តារាងសិស្ស
សម្រាប់សិស្សម្នាក់ៗ អ្នកនឹងឃើញ:

| ព័ត៌មាន | អត្ថន័យ |
|---------|----------|
| **លេខសិស្ស** | Student ID (ឧ: STU-0001) |
| **ឈ្មោះសិស្ស** | ឈ្មោះពេញ |
| **មុខវិជ្ជា** | ចំនួនមុខវិជ្ជាសរុប |
| **ជាប់** | ចំនួនមុខវិជ្ជាជាប់ (≥50%) |
| **ធ្លាក់** | ចំនួនមុខវិជ្ជាធ្លាក់ (<50%) |
| **មធ្យមភាគ** | ពិន្ទុមធ្យមលើគ្រប់មុខវិជ្ជា |
| **វត្តមាន** | អត្រាវត្តមាន (%) |
| **ស្ថានភាព** | អាចឡើងថ្នាក់ ឬ មិនអាច |

#### ស្ថានភាព Status:
- 🟢 **✓ អាចឡើងថ្នាក់:** បំពេញលក្ខខណ្ឌគ្រប់គ្រាន់
- 🟡 **⚠ វត្តមានខ្សោយ:** វត្តមាន < 80%
- 🔴 **✗ ប្រឡងធ្លាក់:** ពិន្ទុមធ្យម < 50%
- ⚪ **មិនមានពិន្ទុ:** មិនមានពិន្ទុប្រលង

---

### ជំហានទី៥: ជ្រើសរើសថ្នាក់ថ្មី

1. នៅផ្នែក **"ថ្នាក់ថ្មី"** (New Classroom)
2. ជ្រើសរើសថ្នាក់ដែលអ្នកចង់ដាក់សិស្សឡើង
   - ឧទាហរណ៍: "ទី៣ | 2026"

#### ⚠️ ការព្រមាន:
- ប្រសិនបើថ្នាក់មិនមានកាលវិភាគ អ្នកនឹងឃើញសារព្រមាន
- សិស្សនឹងមិនឃើញកាលវិភាគនៅពេលឡើងថ្នាក់
- គួរបង្កើតកាលវិភាគមុន ឬបន្ទាប់ពីឡើងថ្នាក់

---

### ជំហានទី៦: ជ្រើសរើសសិស្ស

1. ប្រព័ន្ធនឹង **ជ្រើសរើសសិស្សដែលអាចឡើងថ្នាក់** ដោយស្វ័យប្រវត្តិ ✅
2. អ្នកអាចដោះធីករបស់ (uncheck) សិស្សដែលមិនចង់ដាក់ឡើង
3. អ្នកអាចជ្រើសរើស/ដោះធីករបស់ទាំងអស់ដោយចុច checkbox ខាងលើ

---

### ជំហានទី៧: បញ្ជាក់ការឡើងថ្នាក់

1. ចុចប៊ូតុង **"ដាក់ឡើងថ្នាក់"** (Promote)
2. ប្រព័ន្ធនឹងបង្ហាញការបញ្ជាក់មួយ:
   ```
   តើអ្នកប្រាកដជាចង់ដាក់សិស្សទាំងនេះឡើងថ្នាក់មែនទេ?
   
   ⚠️ ប្រព័ន្ធនឹងពិនិត្យ:
   • ពិន្ទុមធ្យម
   • វត្តមាន
   • ការផ្ទេរកម្រិតត្រឹមត្រូវ
   • មិនអនុញ្ញាតរំលងថ្នាក់
   ```
3. ចុច **OK** ដើម្បីបញ្ជាក់

---

### ជំហានទី៨: ពិនិត្យលទ្ធផល

បន្ទាប់ពីដាក់ឡើងថ្នាក់ អ្នកនឹងឃើញសារមួយ:

#### ✅ ជោគជ័យ (Success):
```
✅ បានដាក់សិស្ស X នាក់ឡើងថ្នាក់ទៅ [ថ្នាក់ថ្មី]។ 
   ប្រវត្តិត្រូវបានរក្សាទុក។
```

#### ⚠️ ការព្រមាន (Warnings):
ប្រសិនបើមានសិស្សខ្លះមិនអាចឡើងថ្នាក់បាន អ្នកនឹងឃើញមូលហេតុ:
```
⚠️ មិនអាចដាក់ឡើងថ្នាក់បាន X នាក់:
• [ឈ្មោះសិស្ស]: មិនអាចរំលងថ្នាក់បានទេ (ថ្នាក់ 1 → ថ្នាក់ 3)
• [ឈ្មោះសិស្ស]: ត្រូវផ្ទេរពីបឋមសិក្សាទៅបឋមភូមិ (Grade 6 → Grade 7)
```

---

## 🔍 អ្វីកើតឡើងនៅពេលឡើងថ្នាក់? (What Happens During Promotion?)

### 1️⃣ ប្រព័ន្ធពិនិត្យ (System Checks):
✅ សិស្សបំពេញលក្ខខណ្ឌឬអត់  
✅ ឡើងថ្នាក់បន្ទាប់ប៉ុណ្ណោះ (មិនរំលងថ្នាក់)  
✅ ផ្ទេរកម្រិតត្រឹមត្រូវ (Grade 6→7, 9→10)

### 2️⃣ រក្សាទុកប្រវត្តិ (Save History):
ប្រព័ន្ធបង្កើត **StudentHistory** record:
- ឆ្នាំសិក្សា (Academic Year)
- ថ្នាក់បច្ចុប្បន្ន (Classroom)
- ពិន្ទុមធ្យម (Average Score)
- វត្តមាន (Attendance)
- ស្ថានភាព: "PROMOTED" ឡើងថ្នាក់

### 3️⃣ ធ្វើបច្ចុប្បន្នភាពសិស្ស (Update Student):
- **ថ្នាក់បច្ចុប្បន្ន →** ថ្នាក់ថ្មី
- **ថ្នាក់មុន →** រក្សាទុកឈ្មោះថ្នាក់ចាស់
- **ថ្ងៃឡើងថ្នាក់ →** ថ្ងៃបច្ចុប្បន្ន
- **ស្ថានភាព →** នៅតែ "ACTIVE" (សកម្ម)
- **កំណត់ចំណាំ →** បន្ថែមព័ត៌មានឡើងថ្នាក់

## 📖 ឧទាហរណ៍ពិតប្រាកដ (Real Example)

### ករណីទី១: ឡើងថ្នាក់ធម្មតា (Normal Promotion)

**ព័ត៌មានសិស្ស:**
- ឈ្មោះ: **សោម សុខា**
- ថ្នាក់បច្ចុប្បន្ន: **ថ្នាក់ទី២ | 2026**
- ពិន្ទុមធ្យម: **75.8%** ✅ (≥50%)
- វត្តមាន: **85.0%** ✅ (≥80%)
