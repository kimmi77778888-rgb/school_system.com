# 📋 មគ្គុទ្ទេសក្រឡាប់ - ស្ថានភាពសិស្ស (Quick Reference - Student Status)

## 🎯 ស្ថានភាពសិស្ស 6 ប្រភេទ

| # | ស្ថានភាព | Code | ពេលណាប្រើ |
|---|----------|------|-----------|
| 1️⃣ | **សកម្ម** | `ACTIVE` | សិស្សកំពុងរៀនធម្មតា |
| 2️⃣ | **ឡើងថ្នាក់** | `PROMOTED` | ទើបឡើងថ្នាក់ថ្មី (ស្វ័យប្រវត្តិ) |
| 3️⃣ | **បញ្ចប់ការសិក្សា** | `GRADUATED` | បានបញ្ចប់ការសិក្សានៅសាលា |
| 4️⃣ | **ផ្ទេរសាលា** | `TRANSFERRED` | ផ្ទេរទៅសាលាផ្សេង |
| 5️⃣ | **ឈប់រៀន** | `WITHDRAWN` | ឈប់រៀនបណ្តោះអាសន្ន |
| 6️⃣ | **ផ្អាកការសិក្សា** | `SUSPENDED` | ផ្អាកការសិក្សាបណ្តោះអាសន្ន |

---

## ⚡ ការប្រើប្រាស់រហ័ស

### 1. មើលសិស្សតាមស្ថានភាព
```
/school/students/?status=ACTIVE      ← សិស្សសកម្ម
/school/students/?status=PROMOTED    ← សិស្សឡើងថ្នាក់
/school/students/?status=GRADUATED   ← សិស្សបញ្ចប់ការសិក្សា
```

### 2. ដាក់សិស្សឡើងថ្នាក់ (ស្វ័យប្រវត្តិ)
```
/school/students/promote/
→ ជ្រើសរើសថ្នាក់ និងសិស្ស
→ ចុច "ដាក់ឡើងថ្នាក់"
→ ប្រព័ន្ធកំណត់ស្ថានភាពជា "PROMOTED" ដោយស្វ័យប្រវត្តិ
```

### 3. ប្តូរស្ថានភាពដោយដៃ
```
Students → Edit → ជ្រើសរើស Status → រក្សាទុក
```

## 🔄 ដំណើរការឡើងថ្នាក់

```
1. សិស្សនៅថ្នាក់ទី១ (Status: ACTIVE)
   ↓
2. ប្រឡងជាប់គ្រប់មុខវិជ្ជា
   ↓
3. ប្រើមុខងារឡើងថ្នាក់
   ↓
4. ប្រព័ន្ធធ្វើស្វ័យប្រវត្តិ:
   ✓ រក្សាទុកថ្នាក់មុន: "ថ្នាក់ទី១ A"
   ✓ ផ្លាស់ប្តូរថ្នាក់: ថ្នាក់ទី២ A
   ✓ កំណត់ស្ថានភាព: PROMOTED
   ✓ រក្សាទុកថ្ងៃឡើងថ្នាក់
   ✓ បន្ថែមកំណត់ចំណាំ
   ↓
5. សិស្សឥឡូវនៅថ្នាក់ទី២ (Status: PROMOTED)
```

## 📊 ព័ត៌មានដែលរក្សាទុក

| វាល | ឧទាហរណ៍ | កំណត់ចំណាំ |
|-----|---------|-------------|
| **classroom** | ថ្នាក់ទី២ A | ថ្នាក់បច្ចុប្បន្ន |
| **previous_classroom** | ថ្នាក់ទី១ A | ថ្នាក់មុន (ស្វ័យប្រវត្តិ) |
| **status** | PROMOTED | ស្ថានភាពបច្ចុប្បន្ន |
| **promotion_date** | 03/08/2026 | ថ្ងៃឡើងថ្នាក់ |
| **notes** | ឡើងថ្នាក់ពី... | ប្រវត្តិពេញលេញ |

## 🎓 ឧទាហរណ៍ស្ថានភាព

### ✅ ACTIVE - សកម្ម
```
សិស្ស: ច័ន្ទ សុខា
ថ្នាក់: ថ្នាក់ទី៣ A
ស្ថានភាព: សកម្ម
→ កំពុងរៀនធម្មតា
```

### ⬆️ PROMOTED - ឡើងថ្នាក់
```
សិស្ស: សុផារ៉ា តន
ថ្នាក់: ថ្នាក់ទី២ A
ថ្នាក់មុន: ថ្នាក់ទី១ A
ស្ថានភាព: ឡើងថ្នាក់
ថ្ងៃឡើងថ្នាក់: 03/08/2026
→ ទើបឡើងថ្នាក់
```

### 🎓 GRADUATED - បញ្ចប់ការសិក្សា
```
សិស្ស: រដ្ឋា ពេជ្រ
ថ្នាក់ចុងក្រោយ: ថ្នាក់ទី១២
ស្ថានភាព: បញ្ចប់ការសិក្សា
ថ្ងៃបញ្ចប់: 15/06/2026
is_active: False
→ បានបញ្ចប់ការសិក្សា
```

### 🔄 TRANSFERRED - ផ្ទេរសាលា
```
សិស្ស: ដារ៉ា សុខ
ស្ថានភាព: ផ្ទេរសាលា
is_active: False
កំណត់ចំណាំ: ផ្ទេរទៅសាលា ABC នៅថ្ងៃទី 10/03/2026
→ ផ្ទេរទៅសាលាផ្សេង
```

## 💾 SQL រហ័ស

```sql
-- មើលសិស្សសកម្ម
SELECT * FROM school_student WHERE status='ACTIVE' AND is_active=1;

-- មើលសិស្សឡើងថ្នាក់ឆ្នាំនេះ
SELECT * FROM school_student 
WHERE status='PROMOTED' 
AND YEAR(promotion_date) = 2026;

-- ស្ថិតិស្ថានភាព
SELECT status, COUNT(*) as count 
FROM school_student 
GROUP BY status;

-- ប្រវត្តិសិស្សម្នាក់
SELECT student_id, first_name, last_name, 
       classroom_id, previous_classroom, 
       status, promotion_date, notes
FROM school_student 
WHERE student_id = 'STU-0001';
```
