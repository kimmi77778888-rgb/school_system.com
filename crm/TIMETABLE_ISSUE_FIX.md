# ការជួសជុលបញ្ហាកាលវិភាគនៅពេលឡើងថ្នាក់
# Timetable Issue Fix for Student Promotion

## 🔍 បញ្ហាដែលបានរកឃើញ (Problem Identified)

នៅពេលដាក់សិស្សឡើងថ្នាក់ទៅថ្នាក់ថ្មី ប្រព័ន្ធមិនបានពិនិត្យមើលថាតើថ្នាក់ថ្មីនោះមានកាលវិភាគដែរឬទេ។ ជាលទ្ធផល សិស្សឡើងថ្នាក់បានជោគជ័យ ប៉ុន្តែពួកគេមិនអាចមើលកាលវិភាគរបស់ខ្លួនបានទេ។

When promoting students to a new grade/classroom, the system did not check if the target classroom had a timetable assigned. As a result, students were successfully promoted but couldn't see their schedule.

### បញ្ហាមូលដ្ឋាន (Root Causes):
1. **គ្មានការពិនិត្យមុន**: មិនមានការព្រមានថាថ្នាក់គោលដៅគ្មានកាលវិភាគ
2. **គ្មានមុខងារចម្លង**: មិនមានវិធីងាយស្រួលដើម្បីបង្កើតកាលវិភាគសម្រាប់ថ្នាក់ថ្មី
3. **ដំណើរការដោយដៃ**: អ្នកគ្រប់គ្រងត្រូវបង្កើតកាលវិភាគដោយដៃសម្រាប់ថ្នាក់ថ្មីនីមួយៗ

## ✅ ដំណោះស្រាយដែលបានអនុវត្ត (Solutions Implemented)

### 1. ការព្រមាននៅទំព័រឡើងថ្នាក់ (Warnings on Promotion Page)

**ឯកសារកែប្រែ**: `school/views.py` - `student_promote()`

បានបន្ថែមការពិនិត្យថាតើថ្នាក់នីមួយៗមានកាលវិភាគឬអត់:

```python
# Check if classroom has timetable
has_timetable = classroom.timetables.exists()
timetable_count = classroom.timetables.count()
next_classrooms_with_timetable_info.append({
    'classroom': classroom,
    'has_timetable': has_timetable,
    'timetable_count': timetable_count
})
```

**ឯកសារកែប្រែ**: `school/templates/school/student_promote.html`

- បង្ហាញសញ្ញា ⚠️ ក្បែរថ្នាក់ដែលគ្មានកាលវិភាគ
- បង្ហាញការព្រមានពេញលេញនៅពេលជ្រើសរើសថ្នាក់គ្មានកាលវិភាគ
- ផ្តល់តំណទៅទំព័របង្កើតកាលវិភាគ

```html
<div id="timetable-warning" class="alert alert-warning">
  <strong>ប្រយ័ត្ន:</strong> ថ្នាក់ដែលបានជ្រើសរើស មិនទាន់មានកាលវិភាគ។
  សូមបង្កើតកាលវិភាគសម្រាប់ថ្នាក់ថ្មីមុន ឬបន្ទាប់ពីឡើងថ្នាក់។
</div>
```

### 2. មុខងារចម្លងកាលវិភាគ (Timetable Copy Feature)

**ឯកសារថ្មី**: `school/views.py` - `timetable_copy()`

បានបង្កើតមុខងារថ្មីដើម្បីចម្លងកាលវិភាគពីថ្នាក់មួយទៅថ្នាក់ផ្សេង:

**លក្ខណៈពិសេស (Features)**:
- ជ្រើសរើសថ្នាក់ប្រភព (ដែលមានកាលវិភាគ)
- ជ្រើសរើសថ្នាក់គោលដៅ (ដែលត្រូវការកាលវិភាគ)
- ជ្រើសរើសឆ្នាំសិក្សាគោលដៅ (ជម្រើស)
- ជម្រើសរក្សា ឬជំនួសកាលវិភាគចាស់
- បង្ហាញចំនួនធាតុកាលវិភាគនៅក្បែរថ្នាក់នីមួយៗ
- ការព្រមានប្រសិនថ្នាក់ប្រភពគ្មានកាលវិភាគ

```python
# Copy timetables
for source_tt in source_timetables:
    Timetable.objects.create(
        classroom=target_classroom,
        subject=source_tt.subject,
        teacher=source_tt.teacher,
        time_slot=source_tt.time_slot,
        academic_year=target_year,
        room=source_tt.room
    )
```

**ឯកសារថ្មី**: `school/templates/school/timetable_copy.html`

ទំព័រ UI ស្អាតសម្រាប់ចម្លងកាលវិភាគ:
- ចែកជា 2 ផ្នែក: ប្រភព និង គោលដៅ
- បង្ហាញចំនួនធាតុកាលវិភាគនៅក្បែរថ្នាក់នីមួយៗ
- ការព្រមានពេលជ្រើសថ្នាក់គ្មានកាលវិភាគ
- JavaScript ដើម្បីបង្ហាញព័ត៌មានបន្ថែមពេលជ្រើសរើស

**ឯកសារកែប្រែ**: `school/urls.py`

បន្ថែម URL pattern:
```python
path('timetable/copy/', views.timetable_copy, name='timetable_copy'),
```

**ឯកសារកែប្រែ**: `school/templates/school/timetable_list.html`

បន្ថែមប៊ូតុង "ចម្លង" ក្នុង topbar:
```html
<a href="{% url 'school:timetable_copy' %}" class="top-btn warning">
  <i class="bi bi-files"></i>ចម្លង
</a>
```

## 📋 វិធីប្រើប្រាស់ (How to Use)

### ករណីទី ១: ឡើងថ្នាក់ដោយថ្នាក់គោលដៅមានកាលវិភាគស្រាប់

1. ចូលទៅ **សិស្ស → ដាក់សិស្សឡើងថ្នាក់**
2. ជ្រើសរើសថ្នាក់បច្ចុប្បន្ន
3. ជ្រើសរើសថ្នាក់ថ្មី (មើលថាមាន ✓ មិនមាន ⚠️)
4. ជ្រើសរើសសិស្សដែលនឹងឡើងថ្នាក់
5. ចុច "ដាក់ឡើងថ្នាក់"

### ករណីទី ២: ឡើងថ្នាក់ហើយថ្នាក់គោលដៅគ្មានកាលវិភាគ

#### វិធី A: បង្កើតកាលវិភាគមុន
1. ចូលទៅ **កាលវិភាគ → ចម្លង**
2. ជ្រើសថ្នាក់ប្រភព (ថ្នាក់ចាស់ដែលមានកាលវិភាគ)
3. ជ្រើសថ្នាក់គោលដៅ (ថ្នាក់ថ្មី)
4. ជ្រើសឆ្នាំសិក្សាថ្មី (ប្រសិនចង់)
5. ចុច "ចម្លងកាលវិភាគ"
6. បន្ទាប់មកទៅឡើងថ្នាក់សិស្ស

#### វិធី B: ឡើងថ្នាក់មុន បន្ទាប់មកបង្កើតកាលវិភាគ
1. ដាក់សិស្សឡើងថ្នាក់ទោះបីមានការព្រមាន
2. ចូលទៅ **កាលវិភាគ → ចម្លង**
3. ចម្លងកាលវិភាគពីថ្នាក់ចាស់ទៅថ្នាក់ថ្មី
4. សិស្សនឹងអាចមើលកាលវិភាគបានភ្លាម

## 🔄 លំហូរការងារដែលណែនាំ (Recommended Workflow)

### សម្រាប់ឆ្នាំសិក្សាថ្មី:

1. **បង្កើតឆ្នាំសិក្សាថ្មី** (ឧទាហរណ៍: 2026-2027)
2. **បង្កើតថ្នាក់សម្រាប់ឆ្នាំថ្មី** (ថ្នាក់ទី 1A, 2A, 3A... សម្រាប់ឆ្នាំ 2026-2027)
3. **ចម្លងកាលវិភាគ**:
   - ពីថ្នាក់ទី 1A (2025-2026) → ថ្នាក់ទី 2A (2026-2027)
   - ពីថ្នាក់ទី 2A (2025-2026) → ថ្នាក់ទី 3A (2026-2027)
   - ជាដើម...
4. **កែសម្រួលកាលវិភាគ** ប្រសិនចាំបាច់ (គ្រូផ្លាស់ប្តូរ, មុខវិជ្ជាផ្លាស់ប្តូរ)
5. **ដាក់សិស្សឡើងថ្នាក់** (គ្មានការព្រមានទៀត!)
